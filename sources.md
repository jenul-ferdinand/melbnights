# Sources

Fetch the ones matching the vibe asked. Each line: vibe | how to get it.

- raves, clubs, techno, house | `scripts/ra.sh <from> <to>` (Resident Advisor, structured JSON, best source for this)
- gigs, live music | https://beat.com.au/gig-guide/ (weekly gig guide, HTML)
- gigs, big shows | https://www.moshtix.com.au/v2/search?CategoryList=&Query=melbourne (Moshtix search)
- bars, pop-ups, food | https://www.broadsheet.com.au/melbourne/events
- general, mainstream | https://www.timeout.com/melbourne/things-to-do/things-to-do-in-melbourne-this-weekend
- general, cheap | https://www.eventbrite.com.au/d/australia--melbourne/free--events/ (free events)
- cheap drinks, happy hours | https://eatdrinkcheap.com.au/melbourne
- uni nights, student parties | WebSearch `"student night" melbourne <weekday>` then Eventbrite

Not fetchable without login: Instagram, Facebook events. If a venue only posts there, tell the user to check the venue's Instagram and link it from `venues.json`.
